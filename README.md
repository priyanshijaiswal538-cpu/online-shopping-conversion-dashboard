# 🛒 Online Shopper Conversion Dashboard

## 📌 Project Overview
An interactive Power BI dashboard that analyzes online shopping sessions and identifies factors that influence purchase conversion.

## 🎯 Objectives
- Analyze visitor behavior
- Understand purchase conversion patterns
- Compare new and returning visitors
- Analyze traffic sources and page views
- Identify factors associated with successful purchases

## 🛠️ Tools & Technologies
- Power BI
- Microsoft Excel / CSV
- Data Visualization
- DAX

## 📊 Dataset
UCI Online Shoppers Purchasing Intention Dataset.

## 📈 Dashboard
The dashboard provides insights into:
- Visitor sessions
- Purchase/conversion rate
- Visitor type
- Traffic source
- Page views
- Session duration
- Monthly and seasonal trends
